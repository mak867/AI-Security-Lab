# 🧪 Lab 01 — Prompt Injection

## Objective

Explore how prompt injection attacks can influence the behaviour of an LLM-based application and examine controls that can reduce the risk.

## Topics

- Direct prompt injection
- Indirect prompt injection
- System prompt protection
- Input validation
- Output filtering
- Least privilege
- AI security monitoring

## Lab Scenario

An AI assistant receives user input and performs tasks based on predefined instructions.

The lab explores whether malicious input can cause the AI system to ignore or override its intended instructions.

## Mitigations

Potential security controls include:

- Strong separation of system and user instructions
- Input validation and sanitisation
- Output validation
- Least-privilege access to tools and data
- Human approval for sensitive actions
- Logging and monitoring
- Testing against known attack patterns
